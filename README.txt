MOVA — prototype 0.1

Contenu:
- index.html : interface mobile et journal alimentaire fonctionnel
- manifest.webmanifest : paramètres d'installation PWA
- sw.js : cache hors ligne de base

Pour tester:
1. Importer ces fichiers dans un projet web statique (par exemple Replit).
2. Lancer le serveur / publier le site en HTTPS.
3. Ouvrir l'URL publiée dans Safari sur iPhone.
4. Partager > Ajouter à l'écran d'accueil.

Fonctions incluses:
- journal par repas
- ajout/suppression d'aliments
- calcul des calories et macros à partir des valeurs pour 100 g et du poids
- objectif calorique modifiable
- sauvegarde locale dans le navigateur

Limites importantes:
- prototype de démonstration, pas encore une application de production
- données stockées uniquement sur cet appareil/navigateur
- pas encore de comptes, base distante, scanner code-barres, recherche de produits, recettes, paiements ni synchronisation
- les valeurs nutritionnelles sont saisies manuellement; vérifier les étiquettes
- aucune recommandation médicale ou de régime n'est fournie
